โครงสร้างไฟล์เว็บไซต์ง้อแฟน (พร้อมอัปโหลดขึ้น GitHub)
====================================================
1. index.html      -> หน้าหลัก (Home Page) มีมิเตอร์วัดอุณหภูมิความโกรธ + ปุ่มกด + ลิงก์ไปหน้าอื่น
2. memories.html   -> หน้ากล่องความทรงจำ (วางโครงสร้างช่องใส่รูปและข้อความไว้ 4 ช่อง)
3. minigame.html   -> หน้ามินิเกมเลือกอุปกรณ์มาแกล้ง/ตี (เชื่อมค่ามิเตอร์กับหน้าหลักอัตโนมัติ)
4. style.css       -> ไฟล์ตกแต่งหน้าตาทั้งหมด (รองรับ iPad และมือถือ)
5. script.js       -> ไฟล์ควบคุมการทำงานทั้งหมด
6. assets/         -> โฟลเดอร์สำหรับเก็บรูปภาพของคุณ (เช่น photo1.jpg, me.jpg)

วิธีนำไปใช้งานบน GitHub Pages:
1. แตกไฟล์ ZIP นี้
2. แก้ไขข้อความในส่วนที่เป็น [...] และนำรูปภาพใส่ในโฟลเดอร์ assets/
3. อัปโหลดไฟล์ทั้งหมดขึ้น Repository บน GitHub แล้วเปิดใช้งาน GitHub Pages ได้เลยครับ
